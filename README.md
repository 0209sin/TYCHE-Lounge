# ORBIT Arcade

플링코, 공통 코인 지갑, 12종 상품(기본 3종 포함), 보관함, 미션, 재기 지원, 로컬 저장과 백업을 갖춘 웹 게임입니다. 홀짝·섯다·경마는 확장 예정 목록이며 아직 플레이할 수 없습니다. 현금 결제, 환전, 광고, 계정 서버는 포함하지 않습니다.

## 실행

Node.js 22 이상에서 프로젝트 폴더를 열고 실행합니다.

```sh
npm ci
npm run dev
```

개발 주소는 `http://127.0.0.1:5173`입니다. 이 폴더의 HTML 파일을 직접 더블클릭해서 실행하는 방식은 지원하지 않습니다.

```sh
npm test
npm run build
npm run preview
```

## Vercel 배포

1. 이 프로젝트를 본인의 GitHub 저장소에 올립니다. `node_modules`와 `dist`는 올리지 않습니다.
2. Vercel에서 **Add New → Project**로 해당 저장소를 가져옵니다.
3. Framework는 **Vite**, Build Command는 `npm run build`, Output Directory는 `dist`입니다. 환경 변수는 필요 없습니다.
4. Deploy 후 정식 프로젝트 주소를 유지합니다. 도메인이 바뀌면 이전 주소의 로컬 저장을 자동으로 읽을 수 없습니다. 도메인 변경 전 백업 내보내기, 변경 후 가져오기를 사용합니다.

Vercel Hobby는 개인·비상업용입니다. 애드센스 등 광고를 추가할 경우 상업용 플랜 또는 이를 허용하는 다른 호스팅이 필요합니다. 본 결과물에는 광고 코드가 없습니다. 새로고침 보상도 없습니다.

## 저장과 복구

- IndexedDB `orbit-arcade` / `save` 저장소에 코인, 구매·장착 상품, 최근 30회 결과, 미션, 설정을 저장합니다.
- 지갑 변경과 상품 소유권은 하나의 readwrite 트랜잭션으로 저장합니다.
- Web Locks로 한 탭에서만 변경할 수 있습니다. 다른 탭은 읽기 전용이며 활성 탭을 닫으면 자동으로 이어받습니다.
- 새로고침·중단 후 미정산 공은 다음 실행 시 한 번 환불합니다. 로컬 게임 특성상 새로고침을 통한 손실 회피를 완벽히 방지할 수 없습니다.
- 이미지/파일 캐시만 삭제하면 일반적으로 저장이 유지되지만, 쿠키 및 사이트 데이터 삭제는 코인·스킨도 삭제합니다. 시크릿 모드 또는 브라우저의 저장소 정리로 사라질 수도 있습니다.
- 설정에서 JSON 백업을 내보내고 검증 후 가져올 수 있습니다. 백업은 암호화되거나 위변조 방지된 것이 아닙니다. 공식 순위·대전·유료 재화에 사용할 수 없습니다.
- 초기화는 `초기화` 입력을 확인한 뒤 해당 게임 프로필만 지우고 10,000코인과 기본 상품으로 시작합니다. 다른 사이트 데이터는 지우지 않습니다.
- 100코인 미만일 때 6시간마다 재기 지원금 500코인. 기기 시각과 로컬 저장에 의존하므로 조작 방지 보장은 없습니다.

## 게임 규칙

공 가격 10/50/100/500, 동시 최대 5개, 배율 20/5/2/0.5/0.5/0.1/0.5/0.5/2/5/20. 지급액은 구매 가격 × 배율이며 원금을 포함합니다. Phaser Matter 실제 물리로 도착 칸을 정합니다. 공끼리는 충돌하지 않습니다. 20초간 공이 도착하지 않거나 보드 이탈 시 구매 가격을 환불합니다. 공이 0.6초 이상 거의 이동하지 않으면 최대 3회 작은 좌우 힘으로 정지 상태를 해소합니다. 현재 설정의 10,000회 물리 시뮬레이션에서 0.1/0.5배 도착 비율 89.94%, 평균 지급률 72.006%, 시간 초과 환불 0회가 관측됐습니다. 이는 고정 확률이나 수익 보장이 아닌 표본 측정값입니다.

## 확장

- `src/catalog.ts`: 상품, 배율, 가격, 미션.
- `src/economy.ts`: 순수 지갑 규칙·백업 검증.
- `src/storage.ts`: 원자적 저장.
- `src/Plinko.tsx`: 실제 물리와 보드 렌더링. Phaser는 진입 시 분리 로딩됩니다.
- `src/App.tsx`: 공통 지갑, 화면과 확인 흐름.
- 새로운 게임은 공통 거래 규칙에 게임별 참가·정산 동작을 추가해야 합니다. 브라우저 지갑을 신뢰하는 경쟁 기능은 추가하지 마세요. 온라인 섯다·공유 경주는 서버 설계가 필요합니다.

읽기 전용 WebMCP 도구는 지원 브라우저에서만 등록됩니다. 미지원 브라우저에서는 일반 플레이가 그대로 작동합니다.
